# Migration checklist: Unity → web stack

Owner decision (2026-11-01): rebuild the game on **Next.js (React) + React Three Fiber + Zustand + Web Audio API + Tailwind + shadcn/ui**, backend on **Supabase** (owner dropped the Rust services, 2026-11-01).
Why: Unity WebGL kept flashing in the browser. Diagnosis before the switch: while the camera turns, whole 64×64-px screen tiles on the walls/bed render with the wrong light (bloom, HDR, MSAA, shadows and the reflection probe each ruled out in headless Chrome; Mac native is clean). Most likely Unity's multi-pass forward lighting (one extra pass per light, depth-equal tested) on Chrome's ANGLE/Metal. three.js lights everything in one pass, so this class of bug goes away.

The new app lives in `web/` (Supabase in `supabase/`). The Unity project (and PRODUCTION.md, referenced below) was removed after parity; it's at git tag `unity-final`.
Loop rule: one item per pass → implement, `npm run build` passes, check in headless Chrome (screenshots + a camera-drag tile check where it renders), tick with a short note, commit. `(ask)` items wait for the owner.
