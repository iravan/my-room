# My Room

A neon bedroom in the browser for showing off your vinyl collection.

- `web/` — the game: Next.js + React Three Fiber + Zustand + Tailwind/shadcn. Run instructions in `web/README.md`.
- `supabase/` — schema, storage bucket and row-level security; `supabase/tests/run-rls.sh` checks the policies.
- `MIGRATION.md` — the Unity → web checklist and what's still open.
- `game_design_document_visual_vinyl_showcase.md` — the original design doc.

The original Unity version lives at git tag `unity-final` (`git checkout unity-final`).
